# Portfolio — Développeur Front-End

Portfolio personnel de Tayyib BASBUNAR, développeur Front-End spécialisé en TypeScript, React et Next.js.

## Site officiel

**Portfolio : https://tayyib-portfolio.vercel.app/**

Cette adresse est l'URL publique de référence. Ne pas utiliser d'URL Vercel temporaire ou de paramètres de suivi (`utm_source`, etc.) dans les liens partagés.

## Stack

- React 18 + TypeScript
- Vite
- Tailwind CSS
- Lucide Icons

## Démarrage

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
