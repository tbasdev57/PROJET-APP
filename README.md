# Portfolio — Développeur Front End

Portfolio personnel de Tayyib BASBUNAR, développeur Front End spécialisé en TypeScript, React et Next.js.

## Stack

- React 18 + TypeScript
- Vite
- Tailwind CSS
- Lucide Icons

## Démarrage

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
